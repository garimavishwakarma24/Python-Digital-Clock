 Python-Digital-Clock
A simple digital clock application built using Python and the Tkinter library.

This project creates a digital clock that displays the current time in hours, minutes, and seconds, along with the date and day of the week. The clock updates in real-time and features a customizable GUI.

Features

- Displays current time in hours, minutes, and seconds
- Displays current date and day of the week
- Updates in real-time
- Customizable GUI with pink background and black text
